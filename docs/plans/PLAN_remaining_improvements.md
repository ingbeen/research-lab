### 조사로 정한 처리안 (결정 불필요 — 근거와 함께)

- **①** `urllib` 이 `URLError(socket.gaierror)` 를 내고 그 `errno` 가 `socket.EAI_NONAME`(「그런 이름 없음」)일 때만, **같은 순간 대조용 도메인(`example.com`)의 이름 해석이 되면** 죽음으로 본다. 대조까지 실패하거나 다른 `errno`(일시 실패 `EAI_AGAIN` 등)면 지금처럼 「판정 못 함」 — 네트워크가 끊겼을 때는 대조도 실패하므로 회차가 통째로 죽지 않는다. DNS 는 메서드와 무관하므로 GET 확인을 붙이지 않는다
- **③** 「한 장당」은 **이번 회차에 문서를 낸 실행 폴더들의 «전체» 새 토큰 ÷ 장수**로 센다(`usage.tokens_of` 가 폴더 전체 합을 준다). 회차 비율(`window_share_percent`)은 지금처럼 차분이다. **뜻이 바뀌므로 로그 열쇠를 새로 짓는다** — `dossier_tokens_new_total` · `dossier_window_share_percent`. 옛 열쇠 `window_share_per_dossier_percent` 는 새 줄에 쓰지 않는다(`tokens_limit_total` → `tokens_new_total` 선례 · 덧붙이기 전용 파일이라 과거 줄은 고치지 않는다)
- **④** 7·8번 표에 「계보」 열을 더한다 — 행의 URL 을 계보 게이트와 **같은 열쇠**(`gate.lineage.normalize_url`)로 계보표에 맞춰 `덩어리 N 원본` · `덩어리 N 복제` · `-`(계보에 없음). 덩어리 번호는 6번 칸의 「덩어리 N」 제목과 같은 번호다. 표 위에 한 줄 — `**N건** · 계보로 묶으면 서로 다른 덩어리 M곳`(계보에 없는 행이 있으면 그 수를 덧붙임)
- **⑥** `payload.as_text` 가 목록은 ` · ` 로, 사전은 `열쇠: 값` 으로 **끝까지** 펴서 돌려준다 — 지금 조립부의 `_flatten` 을 그 자리로 옮기고 조립부는 `as_text` 를 쓴다. 호출처 20곳이 한 함수를 지나 「한 자리만 `str()`」 고장이 구조적으로 사라진다
- **⑦ 지시문 쪽** `lineage._collected_sources` 가 정규화 주소가 같은 출처를 한 줄로 합치고 편을 `찬성·반증` 으로 적는다 — 지금은 같은 URL 이 두 줄로 실려 에이전트가 두 덩어리로 나눌 유인이 있다
- **⑧ 되먹임** 결정 로그에서 그 단계의 **마지막 품질 실패**(러너가 적는 `kind=quality` 줄의 `raw`)를 읽어 지시문 끝에 한 절로 붙인다. 읽기는 로그 모양의 주인인 `decision_log` 가, 붙이기는 새 모듈 하나가 한다(§12 「같은 가드를 두 곳에 두지 않는다」). 반증 세션에는 반증 «자신의» 사유만 가므로 찬성 근거가 새지 않는다
- **⑨** 상한을 「원장에 새로 적은 줄」(담김 + 기각)로 센다. 중복 · 빈 주장은 자리를 먹지 않는다. 상한을 넘은 «새» 주장만 `discarded`(상한 초과)로 남긴다. `_store` 의 반환이 다섯 갈래가 되므로 튜플 대신 작은 dataclass 로 바꾼다
- **⑩** 후보가 박힌 폴더의 그 후보가 원장에서 「안 판」이 아니면 **이어받을 폴더를 고를 때 건너뛴다.** 판정은 `cycle._skip_reason` 의 같은 갈래를 공개 함수(`cycle.closed_candidate_reason`)로 꺼내 둘이 함께 쓴다. 원장을 못 읽으면 「판정 못 함」이라 **지금처럼 이어받는다**(상태 파일을 못 읽을 때 건너뛰는 것과 달리, 여기서 건너뛰면 멀쩡한 미완성을 버린다)

## 7) 리스크(Risks)

- **② 수집 기각 증가** — 표현마다 축을 요구하므로, 에이전트가 `term` 을 빠뜨리고 축 이름에도 그 말이 없으면 **멀쩡한 후보가 영구 기각**된다(기각은 다시 안 판다). 완화: 수집 지시문이 걸린 표현을 정확한 글자로 짚고 `term` 을 JSON 틀에 넣는다 · 축 이름도 대조에 쓴다. 원장의 안 판 후보 5개가 첫 대상이다
- **⑧ 되먹임이 포인터 말을 되돌려 쓰게 할 수 있다** — 자립성 사유는 걸린 표현을 「」로 인용한다. 완화: 붙이는 절이 「그 표현을 다시 쓰지 말라」로 읽히게 쓰고, 절 상수 자체를 자립성 테스트에 넣는다. 잔여 위험은 다음 회차 자립성 게이트가 다시 잡는다
- **⑧ 되먹임은 모든 게이트에 걸린다** — 계보 누락 · 죽은 URL · 측정 설계 · 판정 칸 사유도 다음 시도에 실린다. 의도한 부수효과이나 지시문이 길어진다(사유 한 줄 수준)
- **⑤ 본문 URL 추출 오류** — 한글이 붙은 주소 · 괄호가 든 주소가 잘못 뽑히면 11번 칸에 엉뚱한 주소가 「확인 못 함 / 없었다」로 실린다. 막지 않으므로 회차는 안 죽고, 뽑힌 글자가 그대로 보여 읽는 사람이 가를 수 있다
- **⑤ 판정 단계의 네트워크** — 조립 직전 본문 URL 을 찌른다(최악 URL 당 10초 · 확인 GET 포함 20초). 본문 URL 은 출처 칸 주소를 빼므로 실측상 0 ~ 수 건이다
- **① 도메인이 만료된 옛 출처** — 이름 없는 도메인은 이제 죽음이라 그 출처 칸이 단계를 막는다. 404 와 같은 정책이다(수집은 짚어 다시 묻고, 나머지는 다음 회차 · 되먹임으로 그 주소가 짚인다)
- **③ 로그 열쇠 변경** — 회차 로그를 훑는 쪽이 옛 열쇠만 보면 새 줄에서 값을 못 찾는다. 코드에 그런 쪽은 없다(사람이 훑는다). [주의] 주석에 두 열쇠의 뜻을 적는다
- **⑩ 테스트 변경폭** — `_resolve_run_dir` 를 부르는 진입점 테스트 10여 곳이 원장 인자를 받게 바뀐다
- **⑨ 결정 로그 필드 변경** — 탐색 `judged` 의 `considered` 를 읽는 코드는 없다(테스트 1곳)
