## 3) 배경/맥락(Context)

### 현재 문제점 / 동기

남는 구독 토큰으로 **밤사이 혼자 도는 리서치 파이프라인**을 만든다.
산출물은 수익률이 아니라 **「재볼 가치가 있다/없다」는 근거 문서**이고,
**어느 프로젝트에든 그대로 넘길 수 있게 자립**해야 한다.

설계는 확정됐다(아래 「확정된 설계 결정」). 지금 필요한 것은 **가장 작은 것 하나를
끝까지 도는 뼈대**다. 반증·계보·실현성은 이 뼈대 위에 얹을 자리가 생긴 뒤에 붙인다.

**이번 Phase 가 답해야 할 [미검증] 둘** — 설계서가 남긴 것이며, 짓지 않으면 잴 수 없다.

| 미검증 | 어떻게 잴 것인가 |
| --- | --- |
| `--max-budget-usd` 가 **구독 인증에서 동작하는가** | 아주 낮은 상한(예: 0.01)으로 한 단계를 돌려 중단되는지 본다. 무시되면 토큰을 직접 세는 경로가 필요하다 |
| 한도 소진 시 `--output-format json` 의 **실패 모양** | 일부러 만들 수 없다. **분류 못 한 실패의 원문을 통째로 로그에 남기는 계측**을 심어 두고, 처음 부딪히는 날 답을 얻는다 |

### 전제 추가 (2026-09-12) — 대상 시장에 **미국주식**이 들어온다

사용자 지시로 리서치 대상이 국내주식에 한정되지 않는다.

**이번 Phase 의 「탐색」·「수집」은 시장 중립이라 영향이 거의 없다** — 검색어를 한/영으로
갈아 끼우는 것은 이미 규율이다. 고칠 곳은 `docs/DESIGN.md` 이며 Phase 0 에서 반영한다.

| 자리 | 무엇이 달라지나 |
| --- | --- |
| 기각 신호 「배수를 걸 수 있나」 | 국내는 2배가 상한이지만 **미국은 3배가 있다.** 신호가 시장별로 갈린다 |
| 데이터 카탈로그 | 지금 씨앗이 전부 국내(pykrx · KRX · 국내선물 · ETN)라 **미국 축이 비어 있다.** 채우는 것은 로드맵 Phase 4 이고, 이번엔 「비어 있다」고 명시만 한다 |
| **거래시간 (새 축)** | 미국장은 한국시간 야간이고 서머타임으로 한 시간 움직인다. 「분·초 집행이 필요한가」와 별개로 **「내가 깨어 있는 시간에 집행 가능한가」**가 생긴다 |
| **환율 노출 (새 축)** | 원화 기준 수익이 달러 수익과 다르다. **비용이 아니라 「기준선을 무엇으로 잡나」의 문제**라 5번 칸의 비용·세금·슬리피지 금지에 걸리지 않는다 — 10번 칸(측정 설계 초안)에 붙는다 |

### 🔴 추가 요금은 한 푼도 나오면 안 된다 — 레버를 잘못 잡으면 안 된다

사용자 요구는 **「순수하게 구독 토큰만 쓴다」** 이다. 처음에 `--max-budget-usd 0` 이 검토됐으나
**그것은 잘못된 레버다.**

| 왜 안 되나 | |
| --- | --- |
| 그 플래그의 정체 | **API 달러 지출의 상한**이다. 구독 인증에는 달러 지출 자체가 없다 |
| `0` 을 주면 | 구독에서 **무시되면** 아무것도 안 막고, **강제되면 0달러 = 즉시 중단**이라 한 줄도 못 돈다 |

**과금 경로는 셋뿐이고 전부 인증 문제다.** 그래서 이번 Phase 의 목표 5 는 인증 가드다.

| 경로 | 상태 | 이번 Phase 에서 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` 설정됨 | **[실측 2026-09-12] 호스트에 없음(정상)** | **실행 스크립트가 감지하면 «시작을 거부»한다.** 테스트로 고정 |
| 계정의 추가 사용량(extra usage) 크레딧 | **사용자 확인 필요 — 코드로 볼 수 없다** | `CLAUDE.md` 와 `docs/DESIGN.md` 에 확인 항목으로 남긴다 |
| 컨테이너에 API 키 주입 | 설계상 없음 | 실행 스크립트가 **Claude 토큰 하나만** 넘긴다 |

> **구독 인증은 한도를 다 쓰면 «그냥 멈춘다».** 넘어가서 과금되지 않는다.
> `--max-budget-usd` 는 **과금 방지가 아니라 폭주 감지**용으로만 쓰며,
> 값은 「한 단계가 정상적으로 쓸 양보다 살짝 큰 값」이다.
