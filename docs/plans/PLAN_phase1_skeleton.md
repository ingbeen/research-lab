사용자 지시로 리서치 대상이 국내주식에 한정되지 않는다.

### 🔴 추가 요금은 한 푼도 나오면 안 된다 — 레버를 잘못 잡으면 안 된다

사용자 요구는 **「순수하게 구독 토큰만 쓴다」** 이다. 처음에 `--max-budget-usd 0` 이 검토됐으나
**그것은 잘못된 레버다.**

| 왜 안 되나 | |
| --- | --- |
| 그 플래그의 정체 | **API 달러 지출의 상한**이다. 구독 인증에는 달러 지출 자체가 없다 |
| `0` 을 주면 | 구독에서 **무시되면** 아무것도 안 막고, **강제되면 0달러 = 즉시 중단**이라 한 줄도 못 돈다 |

**과금 경로는 셋뿐이고 전부 인증 문제다.** 그래서 이번 Phase 의 목표 5 는 인증 가드다.

| 경로 | 상태 | 이번 Phase 에서 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` 설정됨 | **[실측 2026-09-12] 호스트에 없음(정상)** | **실행 스크립트가 감지하면 «시작을 거부»한다.** 테스트로 고정 |
| 계정의 추가 사용량(extra usage) 크레딧 | **[사용자 확인 2026-09-12] 꺼져 있음** | 코드로 볼 수 없어 사용자만 확인할 수 있었다. **이 경로는 닫혔다** |
| 컨테이너에 API 키 주입 | 설계상 없음 | 실행 스크립트가 **Claude 토큰 하나만** 넘긴다 |

> **구독 인증은 한도를 다 쓰면 «그냥 멈춘다».** 넘어가서 과금되지 않는다.
> `--max-budget-usd` 는 **과금 방지가 아니라 폭주 감지**용으로만 쓰며,
> 값은 「한 단계가 정상적으로 쓸 양보다 살짝 큰 값」이다.
